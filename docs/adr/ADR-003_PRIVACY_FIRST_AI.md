# ADR-003 — Smart Notes: consent, ephemeral speech and human signoff
**Status:** Product requirement, implementation blocked until compliance review for real recordings.

Separate clinician encounter start from audio start. Zero persistent media/raw transcript in Dental OS. Strict approved draft-only workflow: 2 outputs (clinical + patient), physician review, signed clinical note and separately released patient instructions. No autonomous medical action. Minimize provider payload; validate processor retention, incident logging, hosting region, transfer and consent before patient capture. Use synthetic mocks through early milestones.
