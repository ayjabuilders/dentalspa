# 06 — AI / Agent Contracts (future-ready, no autonomous care)

## Guiding principle
AI is an **optional advisor and draft creator**, not clinical authority and not the source of true workflow state. Introduce a separate runtime only when requirements warrant it; do not force Python infrastructure into Milestone 01.

## Policy-controlled tool access
`list_authorized_upcoming_appointments`, `get_patient_context_minimized`, `get_case_status`, `draft_followup_task`, `draft_patient_instructions`, `propose_staff_reassignment`. All require authenticated actor or service identity, explicit purpose, clinic scope, resource authorization, tool invocation audit and configurable rate limits.

## Action classes
- `observe`: privacy-filtered read. No broad record dump.
- `draft`: reversible note/message/task proposal; shown to a human.
- `execute_low_risk`: possible later only with explicit policy and audit.
- `high_risk`: clinical judgment, prescriptions, patient-facing medical message publication, financial refund, supplier spend, clinical overrides → human approval always.

## First AI milestone — Smart Consultation Notes
- Distinct encounter start and explicit audio capture start; no recording before valid info/consent.
- Stream/process temporarily; no persistent audio or raw transcript in Dental OS.
- Create `ClinicalNoteDraft` and `PatientInstructionsDraft` separately; clinician reviews/corrects/signs.
- Publish patient instructions only upon explicit approval; no autogenerated diagnoses, drugs or follow-up promises.
- AI can suggest tasks; workflow API validates and requires clinician/staff confirmation as appropriate.
- Vendor processor must be reviewed for retention, data residency, transfer, contract terms and logs; 'not saved by our DB' is not a zero-retention guarantee.
- Prefer mocked/synthetic transcripts for testing; abort streaming on stop/disconnect; purge transient buffers; no telemetry payload capture.

## Later agent families (master guide direction)
Patient Coordinator, Operations/Stock, Pulse Coordinator; later Lab/Finance specialized agents. Begin in shadow mode and evaluate false positives, hallucination, permissions and emergency handoff, with kill switch.
