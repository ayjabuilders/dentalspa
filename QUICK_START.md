# How to start with Codex

1. Extract this ZIP into a clean git repository (e.g., `dental-spa-os`).
2. Open the repository folder in Codex. Keep all Markdown specs, JSON schemas and source guide visible.
3. Ask Codex: **"Read AGENTS.md and codex/M01_FOUNDATION_PROMPT.md, inspect the repository, propose your implementation plan, then implement only Milestone 01. Do not deploy or use real patient data."**
4. Provide sandbox Supabase credentials in your own development environment (never in chat or committed). Create separate development/staging projects; configure Vercel after tests.
5. Review the generated screens, tenancy policy and test report. Accept M01 only after `qa/RELEASE_GATES.md` foundation criteria pass.
6. Then run `codex/M02_PATIENT_BOOKING_PROMPT.md`, followed by M03 workflow engine. For real care workflows require Dr Amina's clinical sign-off.

This is a design/package handoff. Running application code is intentionally not pre-generated by this package.
